# 0001：混合检索用 RRF，而不是分数加权

## 背景

向量检索擅长语义相似，BM25 擅长术语精确命中；两路分数的量纲不同（余弦 0~1，BM25 可能 0~10+），直接相加需要归一化和调权重。

## 决策

两路各召回 topN，用 Reciprocal Rank Fusion 按名次融合：`score += 1/(60 + index)`。融合后再进 rerank 精排。

## 结果

- 不用调权重，鲁棒、可复现；
- 丢掉分数强弱信息，靠 rerank 补；
- 代码里是 0-based index，第 1 个是 1/60；按 1-based 名次讲是 1/(60+rank-1)。

## 被否方案

- 向量/BM25 分数归一化后加权：权重依赖语料，换库要重调；
- 只走向量：专有名词、金额、条款编号容易漏。
