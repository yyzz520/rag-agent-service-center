# 企业知识库问答

## 何时使用

- 用户问“制度里怎么规定”“这份文档写了什么”“某条款/流程/标准是什么”
- 回答必须有文档依据，需要能追溯到原文片段
- 需要遵守“无依据不编造”的拒答规则

## 不适用

- 实时状态类问题（批号在哪个库区、库存、工单状态）→ 用 `warehouse-batch-status`
- 纯闲聊、纯计算 → 直接回答或用 calculator

## 输入

- `question`：自然语言问题（必填）
- `doc`：可选，限定在某一份文档内检索

## 执行步骤

1. 调用 `POST /api/v1/rag/chat`，body: `{"question": "...", "doc": "可选"}`
   - 本地直连演示：`python .claude/skills/enterprise-kb-qa/scripts/query_kb.py "问题"`
2. 检查返回的 `sources`：编号 `[n]` 必须能对应到真实原文片段
3. 只依据 `sources` 作答；每个依据句末标注 `[n]`，多来源写 `[1][3]`
4. 检索为空或资料不足时，明确回答“资料中没有相关内容”，**不要编造，也不要在拒答里带引用**

## 输出契约

```json
{
  "answer": "依据原文的回答，句末带 [1]",
  "sources": [{"id": 1, "source": "文件名", "page": 3, "content": "原文片段"}]
}
```

拒答态：

```json
{"answer": "资料中没有相关内容，无法回答。", "sources": []}
```

## 失败处理

- 未登录 / 401：先走 `/api/v1/auth/login` 换 token
- 检索无命中：如实拒答，不切换成模型自答
- 服务不可用/超时：报告失败原因，不伪造答案
- 引用编号找不到对应 source：视为回答不可信，要求重查

## 示例

问题：冷藏库的温控要求是什么？
回答：冷藏库需保持 2~8°C，并配置连续温度监测与超限报警 [1]。

问题：清源缓释片治疗糖尿病的最佳剂量是多少？
回答：资料中没有相关内容，无法回答。（负样本，正确拒答）

## 评测依据

- 检索：61 题固定集，rerank 关→开 recall@1 0.59→1.0、MRR 0.772→1.0
- 生成：12 正 + 8 负，正确率 91.7%、引用正确率 100%、8/8 干净拒答
- 合成语料为项目自带的虚构医药数据，不涉及任何真实业务材料
